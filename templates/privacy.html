Privacy Policy

Listing Pipeline is an eBay listing management tool used to connect seller accounts, import product data, and publish listings through eBay APIs.

Information We Collect

The app may store dashboard user accounts, connected eBay seller account identifiers, encrypted eBay refresh tokens, product information uploaded by an admin user, listing status, and error details returned by eBay APIs.

How We Use Information

Information is used only to authenticate dashboard users, connect seller accounts, create or update eBay listings, show listing history, and maintain the operation and security of the app.

eBay Account Access

eBay OAuth tokens are used only to call authorized eBay APIs for the connected seller account. Refresh tokens are encrypted at rest and are not sold, rented, or shared with third parties.

Data Sharing

The app sends listing and account data to eBay only when needed to perform authorized listing actions. We do not sell personal information.

Data Retention

Data remains in the application database until an authorized admin removes it or the application owner deletes it. Connected eBay accounts can be disconnected from the dashboard.

Security

The app uses dashboard login protection, CSRF protection, password hashing, role-based super-admin controls, and encrypted storage for eBay refresh tokens.

Contact

For privacy questions or data removal requests, contact the owner/operator of this Listing Pipeline deployment.
